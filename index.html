      Clipboard history, not just text
      
          
      
            Text, screenshots and the files you copy land in the Clip tab. Search fuzzily, pin what

            highlighting and images right in the terminal.

      Snippets that do things
      
          
      
            Keep named text snippets for the things you type all day, and command snippets for the
            things you run all day. Enter copies, r runs it in your shell,
            a adds a new one.
          
      
        
      
        
      
          03
          
      Native on Wayland, X11 and TTY
      
          
      
            Talks the Wayland protocol directly and watches X11 selections through XFixes — no
            polling, no desktop extension. On a TTY it still copies via OSC 52. One static Go
            binary, SQLite storage, no config file.
          
      
        
      
      
      

      
      
        
      Questions
      
        
      
          
      
            
      What is Kiipr?
      
            
      
              A terminal (TUI) clipboard manager and snippet expander for Linux. It keeps clipboard
              history for text, images and files, and stores named snippets — including shell
              commands — behind Vim-style keys.
            
      
          
      
          
      
            
      How do I install it?
      
            
      
              Run the install script from the repository, then launch it with
              kiipr. The installer also sets up the background watcher as a systemd
              user unit; check it with
              systemctl --user status kiipr.service.
            
      
          
      
          
      
            
      Which systems does it support?
      
            
      
              Linux on Wayland, X11/XWayland and plain TTYs. X11 needs xclip or
              xsel; GNOME on Wayland uses XWayland. No desktop extensions are required,
              and macOS and Windows are not supported.
            
      
          
      
          
      
            
      How do I navigate it?
      
            
      
              Tab switches Clip ⇄ Snip, j/k moves, i searches, f toggles fuzzy matching, Enter
              copies, d d deletes, u undoes and p pins. In Snip, a adds, e edits and r runs a
              command. ? shows every key.
            
      
          
      
          
      
            
      Does it work over SSH or in tmux?
      
            
      
              Yes. History lives on the machine running kiipr, and copies still reach your terminal
              via OSC 52. Pictures fall back to colour blocks where a graphics protocol cannot pass
              through.
